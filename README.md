## Опис проекту
У цьому репозиторії реалізовано:
1. **Бінарне дерево пошуку (Binary Search Tree, BST):**
   - Побудова дерева шляхом послідовної вставки елементів.
   - Три види обходів: симетричний (Inorder), прямий (Preorder), зворотний (Postorder).
   - Покрокове відстеження та аналіз стека викликів рекурсивної функції `inorderTraversal`.
   - Рекурсивне видалення трьох кореневих елементів (праве піддерево, ліве піддерево, основний корінь).
2. **Червоно-чорне дерево (Red-Black Tree, RB Tree):**
   - Покрокова вставка елементів із дотриманням усіх правил червоно-чорних дерев (перефарбування, ліві та праві повороти).
   - Опрацювання випадків балансування при вставці (Випадок 1: дядько червоний; Випадок 2: пряма лінія; Випадок 3: кут).
   - Видалення трьох чорних вузлів із балансуванням за 5 випадками (Випадки 1–5).
   - Обходи дерева (Inorder, Preorder, Postorder) та порівняння глибини стека рекурсії з BST.
